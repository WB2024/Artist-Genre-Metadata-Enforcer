# Contributing to Artist Genre Metadata Enforcer

Thank you for considering contributing! Here's how:

## Reporting Bugs

Open an [issue](https://github.com/WB2024/Artist-Genre-Metadata-Enforcer/issues) with:
- Your OS and Python version
- Steps to reproduce
- Expected vs actual behavior

## Requesting Features

Open an [issue](https://github.com/WB2024/Artist-Genre-Metadata-Enforcer/issues) describing:
- The use case
- Why it would be useful
- Example workflow

## Submitting Code

1. Fork the repo
2. Create a branch: `git checkout -b feature/your-feature`
3. Make changes
4. Test thoroughly
5. Commit: `git commit -m "Add feature XYZ"`
6. Push: `git push origin feature/your-feature`
7. Open a Pull Request

## Code Style

- Follow PEP 8 (mostly)
- Use type hints where practical
- Keep dependencies minimal (prefer stdlib)
- Test on Debian/Ubuntu if possible

Thanks! 🎶
